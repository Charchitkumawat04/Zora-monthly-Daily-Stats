## 🌐 What is Zora?

[View Dashboard on Dune](https://dune.com/charchitku/zora-monthly-and-daily-stats)

**Zora** is a **decentralized protocol** for creating, discovering, and collecting NFTs — built with creators and communities in mind. It empowers anyone to launch NFT collections, marketplaces, and media experiences without platform lock-in or high fees. Zora's architecture promotes **open-source creativity**, **onchain curation**, and a **permissionless minting** experience.
